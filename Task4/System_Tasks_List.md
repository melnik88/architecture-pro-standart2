# Список крупных задач для каждой системы

## 1. Rate Management Service (расширение существующего)

### Задачи доработки:
- **RMS-1**: Добавление API endpoints для кол-центров
  - GET /api/rates/deposits - получение актуальных ставок
  - GET /api/rates/deposits/personalized/{clientId} - персонализированные ставки
  - Документирование новых API (Swagger)

- **RMS-2**: Разработка SFTP-модуля
  - Создание модуля формирования файлов со ставками (CSV/XML)
  - Реализация SFTP-клиента для отправки файлов партнёрам
  - Планировщик для регулярной отправки файлов
  - Разработка документации для партнёрского кол-центра (формат файлов, расписание, процедуры)

- **RMS-3**: Встроенный мониторинг и метрики
  - Добавление Spring Actuator endpoints для health checks
  - Кастомные метрики для API кол-центров (время отклика, количество запросов)
  - Логирование и метрики SFTP-операций
  - Интеграция с Prometheus/Grafana

- **RMS-4**: Оптимизация производительности и кэширование
  - Анализ и оптимизация запросов к PostgreSQL
  - Настройка connection pooling для базы данных
  - **Кэширование актуальных ставок:**
    - Кэширование ставок с TTL для быстрого отклика кол-центрам
    - Cache invalidation при обновлении ставок в базе данных
    - Мониторинг производительности кэша
  - Асинхронная обработка SFTP-операций

### Оценка времени: 1.5-2 месяца
### Команда: 2-3 разработчика (команда Rate Management Service)

## 2. Система кол-центра банка

### Задачи доработки:
- **CC-1**: Интеграция с Rate Management Service
  - Разработка React-компонента для отображения ставок
  - Интеграция с существующим API Rate Management Service
  - Добавление компонента в существующий интерфейс кол-центра

- **CC-2**: Обработка недоступности сервиса ставок
  - Индикация статуса подключения к Rate Management Service
  - Уведомление сотрудников о технических проблемах
  - Блокировка консультаций по ставкам при недоступности сервиса

- **CC-3**: Обучение сотрудников кол-центра
  - Разработка инструкций по работе с модулем ставок
  - Проведение обучающих сессий для операторов
  - Подготовка FAQ и справочных материалов
  - Пилотное тестирование с группой операторов

### Оценка времени: 0.5-1 месяц (разработка) + 0.5 месяца (обучение параллельно с тестированием)
### Команда: 1-2 разработчика (фронтенд)

## 3. Система партнёрского кол-центра

### Задачи интеграции:
- **PCC-1**: Интеграция с SFTP-модулем системы Rate Management Service
  - Настройка SFTP-клиента для автоматического получения файлов
  - Создание расписания загрузки файлов (например, каждые 15 минут)
  - Настройка безопасности SFTP-соединения
  - Создание парсера для CSV/XML файлов со ставками
  - Реализация валидации данных и обработки ошибок
  - Процедуры импорта ставок в базу данных партнёра
  - Добавление раздела с актуальными ставками в интерфейс
  - Создание справочных материалов для сотрудников
  - Обучение персонала работе с новой функциональностью

### Оценка времени: 1-1.5 месяца
### Команда: Команда партнёра + 1 консультант от банка

## 4. АБС (Автоматизированная банковская система)

### Задачи интеграции:
- **ABS-1**: Проверка существующей интеграции с Rate Management Service
  - Тестирование текущей интеграции из Task3
  - Проверка корректности передачи ставок
  - Документирование существующих процедур

- **ABS-2**: Мониторинг нагрузки от кол-центров
  - Анализ дополнительной нагрузки от запросов кол-центров
  - Оптимизация запросов при необходимости
  - Настройка алертов при превышении нагрузки

### Оценка времени: 0.5-1 месяц
### Команда: 1-2 разработчика АБС (минимальные изменения)

## 5. Тестирование и внедрение

### Задачи QA:
- **QA-1**: Комплексное тестирование интеграции кол-центров
  - **Функциональное тестирование:**
    - Тестирование новых API endpoints для кол-центров
    - Проверка корректности передачи файлов по SFTP
    - Тестирование WebSocket соединений и real-time обновлений
  - **Интеграционное тестирование:**
    - Тестирование интеграции модуля ставок в систему кол-центра
    - Проверка работы обработчика файлов у партнёра
    - Сквозное тестирование процесса консультации клиентов
  - **Регрессионное тестирование:**
    - Проверка работы существующих функций Rate Management Service
    - Тестирование интеграций с сайтом и интернет-банком
    - Проверка производительности под дополнительной нагрузкой

### Оценка времени: 0.5 месяца
### Команда: 2-3 QA инженера

## Общая оценка проекта:
- **Общее время реализации**: 2.5 месяца
- **Общая команда**: 4-6 человек разработки + команда партнёра + тренеры для обучения

## Ключевые изменения в распределении задач:
- **Все функциональные задачи сконцентрированы в соответствующих системах**:
  - Rate Management Service: API, SFTP, мониторинг, оптимизация, конфигурация
  - Кол-центры: интеграционные компоненты
  - АБС: проверка существующих интеграций
- **Преимущества**: максимальное упрощение координации, сокращение времени разработки, повышение качества за счет концентрации экспертизы, следование принципам микросервисной архитектуры
